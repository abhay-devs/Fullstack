# Abhay — React Portfolio

A responsive personal developer portfolio built with React + Vite.

## Run locally
1. Install Node.js (LTS).
2. Extract this project and open the folder in VS Code.
3. In the terminal, run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `src/App.jsx` with your real email.
- Update the LinkedIn URL.
- Update GitHub project links to the exact repositories.
- Add a downloadable resume if desired.
- Review the project descriptions and technology lists for accuracy.

## Build for deployment
```bash
npm run build
npm run preview
```
The production site is generated in `dist/`.
